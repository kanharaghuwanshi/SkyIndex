METHODOLOGY

How SkyIndex Works

01Collect

Airfare observations are collected for configured routes and travel dates.

02Clean

Invalid fares and incomplete observations are filtered before analysis.

03Represent

Median fare is used as the representative value for analytical views.

04Index

Route-level movements can be aggregated into the prototype APIx.

05Visualise

Charts, filters and the observation table expose the resulting data.

Prototype note

The current APIx implementation is an analytical prototype and should not be interpreted as an official government statistical methodology.
